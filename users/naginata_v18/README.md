## オーバーラップ処理(短い重なりの個別打鍵判定)

キープレスが少しでも重なると同時押しと判定するのではなく、重なり時間が閾値
`NG_MIN_OVERLAP_MS`未満なら、同時押しではなく個別の打鍵として
扱います。高速なロールオーバー打鍵(例: F→U をわずかに重ねて打つ)が
「ざ」に誤爆せず「か」+「BS」になります。
0に設定すると、従来通りの同時押し判定になります。
